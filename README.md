# Portfolio

A modern, one-page portfolio website built with React, TypeScript, and Tailwind CSS. Features smooth animations, interactive components, and a clean, professional design.

## Tech Stack

- **React** + **TypeScript** + **Vite**
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **Custom components**: Typewriter, Gallery, Timeline, Apple Carousel, Custom Cursor

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- One-page layout with smooth scrolling navigation
- Custom cursor with interactive hover effects
- Animated typewriter hero section
- Interactive project carousel
- Experience timeline with modal details
- Image gallery with lightbox
- Fully responsive design
